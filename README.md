# ATV Optimizer

Очистка и настройка Android TV-устройств — отключение лишних приложений, смена лаунчеров, установка APK-файлов, настройка HDMI-CEC и согласования частоты кадров, а также получение отчетов о состоянии. Работает на **Nvidia Shield TV, Onn 4K Pro, Chromecast with Google TV, Google TV Streamer** и других Android TV-устройствах. Доступные действия зависят от прошивки устройства и его разрешений.

**Совместимость с Fire TV зависит от сборки.** Некоторые сборки Fire OS отклоняют изменения защищенного штатного лаунчера Amazon, включая попытки его повторного включения. То, что распознан Projectivy или другой поддерживаемый лаунчер, не означает, что прошивка позволяет менять Home или отключать штатный. Приложение отдельно сообщает об ошибке команды, результате превентивного восстановления и фактическом считывании Home; оно не обходит защиту прошивки. См. [issue #205](https://github.com/bryanroscoe/shield_optimizer/issues/205) — отчет о Toshiba Fire TV, всё ещё ожидающий уточнения версии/сборки.

## Какую версию использовать?

Есть два способа запуска. Выберите один — нужно прочитать только соответствующий раздел.

| | **v2 — Десктопное приложение** *(рекомендуется)* | **v1 — PowerShell-скрипт** |
|---|---|---|
| **Для кого** | Для большинства. Установка в один клик, без терминала. | Для пользователей терминала, скриптов, headless/Docker. |
| **Интерфейс** | Нативное оконное GUI | Текстовый интерфейс в терминале |
| **Установка** | Homebrew или загруженный установщик | Установить PowerShell 7, запустить скрипт |
| **Платформы** | macOS, Windows, Linux | macOS, Windows, Linux (PowerShell 7+) |
| **Статус** | Публичная бета | Стабильная, поддерживается |

Обе версии работают через одни и те же команды `adb` и используют общий [каталог функций](docs/FEATURES.md). v1 не исчезает — это поддерживаемый путь для тех, кто предпочитает оставаться в терминале.

## Перед началом (обе версии)

Включите ADB на ТВ — один раз, независимо от используемой версии:

1. **Настройки → Настройки устройства → О телефоне →** нажмите **Build** 7 раз (включит параметры разработчика).
2. **Настройки → Параметры разработчика →** включите **Сетевая отладка** (она же USB/сетевая отладка).

При первом подключении инструмента на ТВ появится запрос **«Разрешить отладку?»** — примите его.

Нативное десктопное приложение — без PowerShell, без терминала, без скриптов. Оно включает собственный `adb` (автоматически загружается при первом запуске), сканирует сеть на наличие устройств при запуске и проводит через все этапы через GUI. Тёмная и светлая темы с переключателем Светлая / Тёмная / Авто.

> **Переименовано:** десктопное приложение теперь называется **ATV Optimizer** (ранее Shield Optimizer). То же приложение, те же настройки, тот же канал обновлений — изменились только название и иконка. Homebrew tap и cask остаются `bryanroscoe/shield-optimizer` / `shield-optimizer`, поэтому `brew upgrade` продолжает работать. Пользователи macOS, установившие приложение из `.dmg`, будут видеть старый `Shield Optimizer.app`, пока не переустановят; его можно безопасно перетащить в Корзину.

## Установка

### macOS — Homebrew (проще всего)

```sh
brew tap bryanroscoe/shield-optimizer
brew install --cask shield-optimizer
```

Homebrew автоматически снимает карантинный флаг macOS, поэтому приложение открывается обычным двойным кликом. Обновляйте позже через `brew upgrade --cask shield-optimizer`.

### Любая платформа — загрузить установщик

Загрузите последнюю версию со [**страницы релизов**](https://github.com/bryanroscoe/shield_optimizer/releases) (текущие сборки помечены `v2-…` и отмечены как *предрелиз* в период беты):

| ОС | Файл |
|----|------|
| Windows | `.msi` или `_x64-setup.exe` |
| macOS | `_universal.dmg` (Apple Silicon + Intel) |
| Linux | `.AppImage`, `.deb` или `.rpm` |

### Первый запуск (неподписанные сборки)

Эти сборки пока не имеют кодовой подписи, поэтому ОС может предупредить при первом запуске. Однократное подтверждение:

- **macOS** (если использовали `.dmg` вместо Homebrew): в macOS 15+ диалог предлагает только *Переместить в корзину* / *Готово*. Нажмите **Готово**, затем выполните `xattr -dr com.apple.quarantine "/Applications/ATV Optimizer.app"`, **либо** откройте Системные настройки → Конфиденциальность и безопасность → **Всё равно открыть**. (Установка через Homebrew полностью пропускает этот шаг.)
- **Windows** (SmartScreen): **Подробнее → Выполнить в любом случае**.
- **Linux**: `chmod +x ATV.Optimizer*.AppImage` перед запуском AppImage.

## Использование

1. Запустите приложение. Оно сканирует сеть и выводит список найденных Android TV-устройств. (Или используйте **Подключить по IP**, **Сканировать сеть** или **Сопряжение по PIN** для устройств на Android 11+.)
2. Примите запрос на отладку на ТВ, если появится.
3. Кликните на устройство, чтобы открыть его. Каждая вкладка — отдельная функция:

**Сканировать сеть** ищет устройства двумя способами: перебором подсети по стандартному порту ADB (5555) — это то, что используют старые устройства вроде Shield, — и через службы mDNS, которые обнаружил сам ADB. Второй способ важен для Android 11+, где беспроводная отладка слушает на *случайном* порту, который меняется при каждом переключении — один перебор портов никогда её не найдёт. Если ТВ рекламирует только службу сопряжения, сканирование сообщает об этом и подставляет адрес сопряжения за вас.

Для беспроводной отладки Android 11+ **Сопряжение по PIN** устанавливает доверие, используя IP:порт и код из **Сопряжение устройства с кодом**. Сопряжение не подключает ТВ. Вернитесь на основной экран беспроводной отладки и введите отдельный IP:порт, указанный там, в **Подключить по IP**; не используйте порт сопряжения повторно. Если ADB автоматически подключит сопряжённое устройство через mDNS, оно появится после обновления списка устройств.

Минимальной или максимальной версии Android нет. Если устройство не появляется — это проблема обнаружения или сопряжения, а не поддержки версии.

| Вкладка | Что делает |
|---------|-----------|
| **Обзор** | Профиль устройства — модель, версия Android, сборка, hardware ID. |
| **Состояние** | Температура, выборки CPU и сети, индикаторы RAM и хранилища, режим дисплея + HDR, аудио и топ потребителей памяти (с вердиктами безопасности). |
| **Воспроизведение** | Что ТВ реально выводит — разрешение, частота, HDR и сквозной аудиоканал. |
| **Лаунчер** | Установка поддерживаемых лаунчеров, запрос установки по умолчанию и явное подтверждение защищённого отключения штатного лаунчера, если прошивка разрешает. |
| **Список приложений** | Постоянное отключение/включение/удаление приложений или установка через Play Store. |
| **Оптимизация** | Мастер очистки — просмотрите рекомендованное действие для каждого приложения с использованием RAM, снимите галочку с тех, что хотите оставить, затем нажмите **Выполнить**. Обратимо через Восстановление. |
| **Твики** | HDMI-CEC, согласование частоты кадров, тайм-аут долгого нажатия, скорость анимации, масштабирование дисплея, сквозной аудиоканал. |
| **Пульт** | Экранный D-pad и ввод текста в реальном времени по низколатентному каналу. Вставьте длинный URL или пароль вместо набора вручную. |
| **Файлы** | Просмотр `/sdcard`, загрузка файлов на этот компьютер, выгрузка и поиск экспортированных резервных копий приложений. |
| **Установка APK** | Установка `.apk` из папки. |
| **Снимок** | Сохранение состояния устройства и повторное применение позже — на том же устройстве (откат) или на другом (клонирование). |
| **Shell** | Прямой запуск команды ADB shell для всего, что не покрывает интерфейс. |

Кураторский **список «не отключать»** блокирует отключение критически важных пакетов на всех путях, а **Восстановление** повторно включает все отключённые пакеты, если когда-нибудь понадобится чистый старт.

Сборка из исходников / участие в разработке? См. [`v2/README.md`](v2/README.md).

Оригинальный кроссплатформенный инструмент PowerShell. Те же функции, терминальный интерфейс. Требует **PowerShell 7+**.

## Установка PowerShell 7 + получение скрипта

<details>
<summary><b>Windows</b></summary>

Требуется PowerShell 7; рекомендуется Windows Terminal.

**winget (рекомендуется)**
```powershell
winget install --id Microsoft.PowerShell; winget install --id Microsoft.WindowsTerminal
```

**Или загрузите установщики**
- PowerShell 7: [релизы на GitHub](https://github.com/PowerShell/PowerShell/releases/latest) — нужен `.msi`
- Windows Terminal: [Microsoft Store](https://aka.ms/terminal)

Затем откройте Windows Terminal → PowerShell 7 и выполните `pwsh .\Shield-Optimizer.ps1`.
</details>

<details>
<summary><b>macOS</b></summary>

```bash

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Установите PowerShell
brew install powershell
```

Альтернатива: установщик `.pkg` из [релизов PowerShell](https://github.com/PowerShell/PowerShell/releases/latest).
</details>

<details>
<summary><b>Linux (Debian/Ubuntu)</b></summary>

```bash
sudo apt-get update
sudo apt-get install -y wget apt-transport-https software-properties-common
wget -q "https://packages.microsoft.com/config/ubuntu/$(lsb_release -rs)/packages-microsoft-prod.deb"
sudo dpkg -i packages-microsoft-prod.deb
sudo apt-get update
sudo apt-get install -y powershell

pwsh ./Shield-Optimizer.ps1
```
</details>

<details>
<summary><b>Linux (Docker)</b></summary>

> *Должно работать, но не проверено полностью.* Основано на рабочем процессе, который @shawly описал в [#9](https://github.com/bryanroscoe/shield_optimizer/issues/9).

`--network host` обязателен, чтобы скрипт мог сканировать локальную сеть; `iproute2` нужен внутри контейнера для автообнаружения.

```bash
docker run -it --rm --network host mcr.microsoft.com/powershell:latest

# Внутри контейнера:
apt-get update && apt-get install -y iproute2
Invoke-WebRequest -Uri https://github.com/bryanroscoe/shield_optimizer/raw/refs/heads/main/Shield-Optimizer.ps1 -OutFile Shield-Optimizer.ps1
./Shield-Optimizer.ps1
```

> **Примечание:** `--network host` работает только на нативном Linux. В Docker Desktop для macOS/Windows автообнаружение не увидит локальную сеть — установите PowerShell нативно или используйте **Подключить по IP**.
</details>

**Получить скрипт:** загрузите `Source code (zip)` со [страницы релизов](https://github.com/bryanroscoe/shield_optimizer/releases/latest) или выполните `git clone https://github.com/bryanroscoe/shield_optimizer.git`. Запускайте из папки, где он находится.

## Запуск

```powershell
pwsh ./Shield-Optimizer.ps1
```

ADB-инструменты загружаются автоматически при первом запуске. Несколько флагов:

```powershell
pwsh ./Shield-Optimizer.ps1 -ForceAdbDownload   # повторно загрузить ADB-инструменты
pwsh ./Shield-Optimizer.ps1 -LightMode          # принудительно светлая тема
pwsh ./Shield-Optimizer.ps1 -DarkMode           # принудительно тёмная тема
```

(Тема автоопределяется по системным настройкам; флаги только переопределяют её.)

<details>
<summary><b>Устранение неполадок</b></summary>

**Windows — «Running scripts is disabled on this system»**

PowerShell по умолчанию блокирует неподписанные скрипты. Либо однократно задайте политику выполнения (PowerShell 7 от имени администратора):
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
либо обойдите для одного запуска: `pwsh -ExecutionPolicy Bypass -File .\Shield-Optimizer.ps1`.

**Windows — ошибки скрипта или не запускается**

Убедитесь, что используется **PowerShell 7**, а не Windows PowerShell 5.x (синяя иконка). Проверьте через `$PSVersionTable.PSVersion` — основная версия должна быть 7+. Запускайте из выпадающего списка Windows Terminal → «PowerShell» (не «Windows PowerShell»).

**Другие проблемы**

| Проблема | Решение |
|----------|---------|
| Устройство не найдено | Включите Network Debugging, попробуйте Scan Network, проверьте ТВ на наличие запроса авторизации |
| Устройство показывает UNAUTHORIZED | Примите запрос «Разрешить USB-отладку?» на ТВ |
| Лаунчер не переключается | Проверьте диагностику Launcher Wizard и фактическое считывание Home. Некоторые прошивки отклоняют изменение защищённого штатного лаунчера; повторная попытка захвата не снимает это ограничение. |
| Что-то сломалось | Восстановление может запросить повторное включение отключённых пакетов; проверяйте reported failures, так как прошивка может отклонять изменения. |
| Неправильный тип устройства | Проверьте Profile; обнаружение использует brand/model/packages |
| Сканирование ничего не находит (macOS/Linux) | Убедитесь, что Network Debugging включён; попробуйте Connect IP |
| Цвета плохо читаются | Попробуйте `-LightMode` или `-DarkMode` |
</details>

## Безопасность

- **Отключение важнее удаления** — повторное включение отключённого приложения зависит от разрешений прошивки; удаление может привести к потере данных, которые Восстановление не сможет вернуть.
- **Восстановление** — запрашивает экстренное повторное включение отключённых пакетов и сообщает о неудачах.
- **Список «не отключать»** защищает системно-критические пакеты на всех путях кода.

**Используйте на свой риск.** Модификация системных приложений несёт определённый риск, но этот инструмент ставит во главу безопасные и обратимые изменения.
